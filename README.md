# 艾泽拉斯职业罗盘

综合“颜值”和“手感”两条偏好轴，为《魔兽世界》正式服玩家推荐适合尝试的职业专精。

## P2 功能

- 颜值题与手感题交替出现、并行计分
- 两条轴各占最终契合度的 50%
- 每道题都可选择“我无所谓”，中立答案不会强行影响专精匹配
- 输出 `N% · 专精` 的首选结果与 9 个备选
- 额外给出 5 个职业推荐；中立答案较多时优先展示多玩法职业
- 专精介绍与职业介绍分开呈现
- 13 个职业与 40 个专精均提供面向新玩家的完整介绍和独立优缺点
- 展示颜值/手感分项、推荐理由与玩法提醒
- 独立询问上手难度与操作上限，并按正式服 12.1 资料校准
- 为 40 个专精与 13 个职业提供 0.0～9.0、精确到 0.1 的六维体验图和完整评分图鉴
- 右上角 `VII` 隐藏入口内置七宗罪恶搞测试，与正式评分完全隔离
- 覆盖《至暗之夜》正式服 13 个职业、40 个专精
- 纯前端、无需登录、适配手机与桌面

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
